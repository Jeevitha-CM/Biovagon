## Running locally

No setup needed. Just open `index.html` in any web browser.

> Tip: for the best experience (so all links and images load correctly), open the whole folder in a simple local server — e.g. the **Live Server** extension in VS Code.

---

## Deploying

This is a static site, so it deploys anywhere:

1. **Netlify** *(recommended)* — connect this GitHub repo at [app.netlify.com](https://app.netlify.com); it auto-deploys on every update. No build command needed; publish directory is the root (`/`).
2. **GitHub Pages** — Settings → Pages → Deploy from `main` branch.
3. **Render** — New → Static Site → publish directory `/`.

---

## Updating the site

1. Edit the relevant `.html` file (or have changes made for you).
2. Upload/commit the changed files to this repo.
3. Netlify automatically rebuilds and goes live in ~30 seconds.
